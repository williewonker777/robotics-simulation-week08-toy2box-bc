# 등록된 판정 코드

`artifacts/experiments/registered_results.json`을 만든 분석 코드입니다(파이프라인 S8, 결과 확인 전 고정).
입력에 생성 데이터(Mimic 500개)와 생성 시도 파일이 필요해 이 저장소만으로는 다시 돌릴 수 없습니다.
같은 판정 규칙을 저장소 자료만으로 다시 계산하는 도구는 [`../verdicts.py`](../verdicts.py)입니다.
아래 두 파일은 기계 경로만 지웠고 판정 로직은 그대로입니다.

| 파일 | 내용 |
|---|---|
| `cde2_analysis.py` | 조건별 집계(단계, 닫는 순간 자세, 생성 수율, 규칙 준수율)와 두 비율 검정 |
| `cde3_analysis.py` | 사전 등록 2·3의 H1″·H3 판정 |

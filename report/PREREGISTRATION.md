## 사전 등록 1 (2026-10-27 13:55, H1 생성 전)

### 주 가설 H1: 대칭을 무시한 원본 선택

- **원인:** 원본 시범은 트럭 yaw를 고르게 덮지 않습니다(|yaw| > 90°에 35개, ±(45~90)°에 0개). stock Mimic은 트럭의 180° 대칭을 모른 채 원본을 고릅니다.
  그래서 |yaw| ≤ 90° 생성 데이터는 먼 원본을 큰 각도로 돌려 만들어지고, 잡는 자세가 뒤섞이고 시작 때 손목 회전이 커집니다.
  BC 정책은 닫는 순간 손목 방향을 맞추지 못해 파지에 실패합니다.
- **개입 E1 (Mimic 축):** 생성 래퍼 옵션으로 트럭 프레임을 yaw ∈ (−90°, 90°]로 접습니다. 범위 밖이면 트럭 z축으로 180° 돌린 프레임을 씁니다.
  같은 규칙을 원본 주석의 트럭 자세와 생성 중 현재 트럭 자세(원본 선택과 변환에 쓰는 값)에 모두 적용합니다.
  원본 궤적, 행동, 관측, 학습 관측, 환경, 성공 판정은 그대로입니다.
- **고정 조건 (E0와 같음):** 원본 40개, 생성 래퍼 설정, 첫 subtask의 `nearest_neighbor_object` 기본값(nn_k 3, 위치·회전 가중치 1), 학습용 생성 수 500개, BC 설정 전부, 학습 seed 101·111, 평가 seed 42·100회·horizon 800.
- **메커니즘 예측 (E1 대 E0)**
  1. 생성 데이터: 모든 yaw 구간에서 잡는 순간 그리퍼 방향이 (−90°, 90°] 규칙을 따르는 비율이 95% 이상이고, |yaw| ≤ 90° 생성 수율이 E0보다 오른다.
  2. rollout: |yaw| 45~90°에서 닫는 순간 방향 오차 중앙값이 27.4°에서 10° 아래로 내려가고, 파지 실패 수가 E0(93/200)보다 줄어든다.
  3. 성공률: |yaw| ≤ 90° 성공이 E0의 7/99보다 크게 오르고, |yaw| > 90° 성공은 E0의 32/101과 비슷하며, 평균 성공률이 E0 19.5%보다 높다.
- **판정:** 지지는 (두 seed 모두 E0의 같은 seed보다 높음) + (200회 합산 두 비율 검정 단측 p < 0.05) + (예측 2 성립). 기각은 평균이 오르지 않거나 예측 2가 성립하지 않을 때. 나머지는 보류.

### 대조 가설 H2: 데이터 양

## 사전 등록 2 (2026-10-27 14:45, H1″ 시범 수집 전)

### 주 가설 H1″: 원본 시범의 방향 공백

- **원인:** 원본 40개가 트럭 yaw를 고르게 덮지 않습니다(|yaw| > 90°에 35개, ±(45~90)°에 0개).
  Mimic은 이 공백을 채우지 못합니다. 먼 원본을 변환하면 잡는 자세가 섞이고, 대칭 접기는 물리적으로 실패합니다.
  그래서 정책은 공백 구간에서 자세를 정하지 못하고 파지·접근에 실패합니다.
- **개입 E1 (데이터 축):** 같은 수집 제어기와 같은 설정으로 |yaw| ≤ 90° 배치에서만 시범 20개를 더 모읍니다.
  (−90°, 90°]를 45° 구간 4개로 나눠 5개씩 할당합니다. 원본은 40 + 20 = 60개입니다(과제 범위 20~100).
  배치는 수집 단계에서 reset을 반복해 고르며, 환경 코드와 배치 분포는 바꾸지 않습니다.
- **대조 E2 (개수 대조):** 같은 제어기로 yaw 필터 없이 20개를 더 모읍니다(40 + 20, 자연 분포). 개수는 E1과 같고 방향 범위만 다릅니다.
- **고정 조건:** 생성 래퍼 설정(stock 매칭, 접기 없음), 학습용 생성 500개, BC 설정, 학습 seed 101·111, 평가 seed 42·100회·horizon 800.
- **E3 (최종 후보):** E1 원본으로 생성 1000개(E1의 500개 + 새 chunk seed 500개). E1 대비 양만 다릅니다.
- **예측**
  1. 생성 데이터: E1에서 ±(45~90)° 구간의 잡기 규칙 준수율이 95% 이상이다(E0는 58.5%, 65.7%).
  2. 정책: ±(45~90)°에서 닫는 순간 '그 사이' 자세가 25/55의 절반 아래로 줄고, |yaw| 45~90°의 방향 오차 중앙값이 27.6°에서 10° 아래로 내려간다.
  3. 성공: |yaw| ≤ 90° 성공이 E0의 7/99보다 오르고, 두 seed 평균이 E0의 19.5%보다 높다.
  4. 대조: E2의 |yaw| ≤ 90° 성공은 E0와 비슷하고, 전체 개선은 E1보다 작다.
- **판정**
  - 지지: 세 가지를 모두 만족한다.
    - 두 seed 모두 E0의 같은 seed보다 전체 성공이 높다.
    - |yaw| ≤ 90° 합산 성공이 E0보다 높고, 두 비율 검정에서 단측 p < 0.05다.
    - 예측 2가 성립한다.
  - 기각: |yaw| ≤ 90° 성공이 오르지 않거나, 예측 2가 성립하지 않는다.
  - E2가 E1과 비슷하게 오르면 방향 범위보다 개수가 원인으로 보고 H1″의 특이성을 기각한다.
  - 전체 200회 합산 단측 p도 함께 보고한다.
- **최종 모델:** E1과 E3 중 전체 합산 성공이 높은 쪽입니다. 같으면 E3입니다. E2가 둘 다 넘으면 E2로 하고 그 사실을 적습니다.

### 수집 규칙

- 설정은 원본 40개의 최종 수집과 같습니다: `--control_mode smooth`, `--max_steps 1600`, `--max_final_xy 0.055`, 같은 품질 기준과 annotation.
- E1은 seed 3611, E2는 seed 3612로 수집합니다.
- 시도마다 정착 후 트럭의 yaw·x·y를 기록해, yaw 구간별 수집 성공률(생존 편향 가설)을 잽니다.

## 판정 방법

- 성공률은 관측 평가기(`scripts/tools/evaluate_toy2box_bc.py`)로 냅니다. 이 도구는 stock `play.py`를 그대로 실행하고 매 step 상태를 기록합니다. E0에서는 stock 실행과 성공 vector가 200/200 같았습니다.
- 최종 2개 모델은 stock `play.py` 강의 명령으로 다시 확인합니다.
- 정책이 다르면 같은 평가 seed라도 rollout별 배치가 달라질 수 있어 짝을 짓지 않은 두 비율 검정을 씁니다.
- 단계 분류는 `scripts/tools/toy2box_analysis/stage_v3.py`(v3.1), 메커니즘 지표는 `close_precision.py`와 `dataset_convention.py`입니다.

### 보충 1 (2026-10-27 17:05, 교정 데이터 생성 전): 건너뛰는 경우
